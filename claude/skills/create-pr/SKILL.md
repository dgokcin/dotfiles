### GitHub PR Command

```bash
gh pr create \
  --head $(git branch --show-current) \
  --base <base-branch> \
  --title "type(scope): Description here" \
  --body "## Summary
Brief description of changes

## Changes
- Change 1
- Change 2

## Additional Notes
Any extra context"
```

### GitLab MR Command (ugh)

```bash
glab mr create \

- Change 2

## Additional Notes
Any extra context"
```

### Rules

- **USE NORMAL SENTENCE CASING** - PR/MR is NOT lowercase like commits
- Capitalize first letters of sentences, proper nouns, headings
- Write like a human would write documentation
- Mandatory sections: Summary, Changes, Additional Notes
- After creation, provide URL: `[PR Title](URL)`
- **FORBIDDEN**: No AI attribution, no "Generated by", no "Co-Authored-By"
- If ticket in branch name, include in title: `feat(DEVX-123): Description`
